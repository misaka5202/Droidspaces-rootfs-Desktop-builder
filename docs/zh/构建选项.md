# 构建选项

在 GitHub Actions 的 `Run workflow` 页面选择目标、桌面和附加功能。所有目标都通过 Anland Wayland 输出，RootFS 面向 ARM64 Droidspaces 容器。

## 发行版与桌面支持

| 构建目标 | 基础镜像 | 可选桌面 |
| --- | --- | --- |
| `Debian-13` | Debian 13 (trixie) | `KDE`、`KDE mobile`、`GNOME`、`Niri`、`Hyprland`、`Mango`、`Denial` |
| `Ubuntu-26` | Ubuntu 26.04 | 同上 |
| `Fedora-43` | Fedora 43 | 同上 |
| `Fedora-44` | Fedora 44 | 同上 |
| `Arch` | Arch Linux ARM | 同上 |

`all` 根据桌面能力筛选并构建可用目标。`all-wayland` 为全部八种桌面构建 Debian 13、Ubuntu 26、Fedora 43/44 与 Arch 五种目标。显示后端固定为 `anland-wayland`，没有 X11 后端，也没有纯命令行的 `none` 桌面。

| 桌面 | 用途与说明 |
| --- | --- |
| `KDE` | KDE Plasma 桌面。 |
| `KDE mobile` | 面向手机屏幕和触控的 Plasma Mobile。 |
| `GNOME` | 完整 Anland Wayland 桌面。包含终端、文件管理器、设置、系统监视器、密钥环、门户和常用文档/媒体应用。 |
| `Niri`、`Hyprland`、`Mango`、`Denial` | Anland Wayland 合成器。提供基础终端、XDG portal、音频和字体服务，不预装完整桌面应用。 |

## 工作流输入

| 输入 | 可选值 / 默认值 | 说明 |
| --- | --- | --- |
| `build_target` | `Debian-13`、`Ubuntu-26`、`Fedora-43`、`Fedora-44`、`Arch`、`all`、`all-wayland`；默认 `Debian-13` | 选择构建目标。 |
| `custom_username` | 1–32 位字母、数字、`_`、`-`；以字母或 `_` 开头；默认 `Gold` | RootFS 普通用户名称。 |
| `desktop` | `KDE`、`KDE mobile`、`GNOME`、`Niri`、`Hyprland`、`Mango`、`Denial`；默认 `KDE` | 选择主桌面，也就是负责开机自启动的桌面。 |
| `extra_desktops` | 逗号分隔的桌面名，例如 `Niri,Hyprland`；默认留空 | 额外构建的桌面，与主桌面组成构建矩阵；留空表示只构建主桌面。`all-wayland` 构建目标下该选项会被忽略。 |
| `desktop_autostart` | `true` / `false`；默认 `true` | 安装桌面自启动服务。 |
| `display_backend` | `anland-wayland` | 显示后端，目前只有这一种。 |
| `PulseAudio` | `socket` / `tcp` / `none`；默认 `socket` | 音频转发方式；Anland 会自动设为 `none`。 |
| `enable_zh_tz` | `true` / `false` | 安装中文 locale 并设置上海时区；中英文工作流默认值不同。 |
| `gpu_vendor` | `qualcomm` / `mediatek`（双版本工作流还有 `both`）；默认 `qualcomm` | 构建哪个 GPU 版本。`qualcomm` 装 Adreno 版 Mesa 并设置 kgsl；`mediatek` 会清掉这些变量、改装标准软件驱动。 |
| `enable_mesa` | `true` / `false`；默认 `true` | 安装 Mesa 驱动：高通装 Adreno 版，MTK 装标准软件驱动。 |
| `enable_8gen2_wayland` | `true` / `false`；默认 `false` | 为相关设备设置 Turnip UBWC Wayland 修复参数。 |
| `nosnap` | `true` / `false` | 仅 Ubuntu：移除 Snap、snapd 并阻止其被 APT 重新安装；中英文工作流默认值不同。 |
| `enable_systemd257` | `true` / `false`；默认 `false` | 在旧 Android 内核场景尝试安装 systemd 257 包族；只支持普通 `KDE`。 |
| `enable_srf` | `true` / `false` | 安装 Fcitx5；中文工作流默认开启，英文工作流默认关闭。 |
| `enable_binfmt` | `true` / `false`；默认 `false` | 添加 binfmt 跨架构支持；当前不建议用于 Arch。 |
| `enable_yj` | `true` / `false`；默认 `true` | 增强 NAT 与 Android/Droidspaces 硬件识别。 |
| `enable_kfgj` | `true` / `false`；默认 `false` | 安装编译器、CMake、Python 等开发工具。 |
| `enable_zip` | `true` / `false`；默认 `true` | 安装常用压缩工具。 |
| `enable_docker` | `true` / `false`；默认 `false` | 在 RootFS 中安装 Docker 相关软件包。 |
| `wayland_package_repository` | 公开的 `owner/repository`；默认 `Goldzxcbug/droidspaces-package` | 指定预编译 Anland 软件包 Release 的来源。 |

完整的 workflow 默认值可在 `.github/workflows/build-rootfs-releases.yml`（中文）和 `build-rootfs-releases-en.yml`（英文）中查看。`enable_systemd257` 属于实验性旧内核兼容选项，会增加构建时间；systemd 已为 257 或更低版本的系统会跳过安装，详见[脚本说明](../../scripts/README.md)。

## 自动生成的 Droidspaces 推荐配置

原生和 QEMU 构建都会按最终生效的选项生成 `container.config`，将其作为归档的第一个
普通文件，再写入 rootfs 内容并压缩为 XZ。原包中的旧同名配置会被移除，无需在
Dockerfile 中另加 `COPY`。支持推荐配置的 Droidspaces 安装向导会自动载入这些值。

| 构建选项 | 推荐配置 |
| --- | --- |
| 显示后端 `anland-wayland` | `enable_anland=1`，`enable_termux_x11=0` |
| KDE 或 KDE Mobile | `allow_userns=1` |
| 安装 Docker | `net_mode=nat`，未选择时沿用 app 默认值 |
| 开启高通骁龙 GPU 支持 | `enable_gpu_mode=1` |
| `enable_zh_tz=true`（启用中文 locale 和上海时区） | `dns_servers=114.114.114.114` |

字段名沿用 Droidspaces 的 Anland 分支。挂载路径仅写入配置，由 Droidspaces 已有的
`bind_mounts` 解析和挂载流程处理。环境变量不通过这份推荐配置传递。KDE 的用户命名
空间选项在不支持的内核上保持推荐的开启显示，但开关灰显，不表示内核提供了该功能。

本地验证配置映射和打包顺序：`python3 -m unittest discover -s tests -v`。
